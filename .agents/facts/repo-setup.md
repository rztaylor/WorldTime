# Repository setup facts

- Repository classification: greenfield browser application initialized from `docs/PRODUCT.md`.
- Package manager: npm with a committed lockfile.
- Runtime stack: Vite, React, TypeScript, Tailwind CSS, Luxon, react-simple-maps with d3-geo, dnd-kit, and Lucide.
- Source root: `src/`; browser tests: `tests/`; developer documentation: `docs/dev/`.
- Bundled geographic data: `world-atlas` map shapes, `countries-and-timezones` and `countries-list` country/IANA records, and a GeoNames city extract generated by `scripts/build-city-catalog.mjs`. Core behavior must not require network access.
- Repeated validation is exposed through package scripts, especially `npm run check`.
